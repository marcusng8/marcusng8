### What I do

**Revenue-critical backend systems.** Eight NestJS microservices on Cloud Run + Cloud SQL PostgreSQL 15, ingesting webhooks from 89 ad and checkout platforms. Money is handled as fixed-point strings, never floats — decimal drift in financial aggregates is not a rounding problem, it is a trust problem. Webhooks are acknowledged immediately and processed asynchronously, with dead-letter queues and progressive retry windows rather than silent loss.

**Calibrated decision layers.** Models that answer typed questions with probabilities instead of writing prose, so autonomous code can threshold, escalate or abstain. Everything is gated on Expected Calibration Error against a pre-registered bar — and the configurations that fail are published as failures. → [research](https://marcusnavarrogabrich.com/research)

**Quantitative systems.** Automated execution and market monitoring (Python / MQL5) with programmed risk-containment locks, designed to run unattended.
